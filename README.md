# 科研通用底座

从零研究经验到 PhD 申请准备的中文交互教材：8个阶段、24章、100篇教程，其中60篇实证定量主修。

**在线阅读：https://zwbsdmzdsx-hue.github.io/academic-research-foundations/**

## 内容

覆盖研究思考、文献检索、研究问题、创新贡献、方法选择、证据分析、论文结构与写作、合作评审及PhD申请表达。包括四类原创教学样稿、逐句批注、28周建议路线和可复算材料。

## 使用

直接打开网站，或下载 `index.html` 后离线阅读。搜索、阅读标记、练习草稿、测验、自检和研究工具均在浏览器中运行，无需账户。

学习记录保存在当前浏览器，不会上传到本仓库，也不会自动跨设备同步。请在“记录与备份”导出JSON；本地文件版本的进度需导出后再导入在线版本。

旧版教材位于 `legacy/index.html`；教学CSV、Python和表格操作说明位于 `materials/`，也可从网站内下载。

## 教学材料

示范数据为人工构造，访谈和文本样稿为原创教学情境，不能作为实际科研成果。各学科方法、报告与申请要求按相关机构和具体研究条件理解。

本仓库通过GitHub Pages发布静态网页。更新根目录 `index.html` 后推送到 `main`，Pages会重新发布。
