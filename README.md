# 科研通用底座

从零研究经验到 PhD 申请准备的中文交互教材：8个阶段、24章、100篇教程，其中60篇实证定量主修。

**在线阅读：[GitHub Pages](https://zwbsdmzdsx-hue.github.io/academic-research-foundations/)**

## 内容

覆盖研究思考、文献检索、研究问题、创新贡献、方法选择、证据分析、论文结构与写作、合作评审及 PhD 申请表达。包括四类原创教学样稿、逐句批注、28周建议路线和可复算材料。正文已按 Humanizer-zh 与 Stop Slop 的规则做过语言审读，减少套话和模板式表达，同时保留方法术语、数字、引用和结论边界。

## 使用

直接打开网站，或下载 `index.html` 后离线阅读。搜索、阅读标记、练习草稿、测验、自检和研究工具均在浏览器中运行，无需账户。

学习记录保存在当前浏览器，不会上传到本仓库，也不会自动跨设备同步。请在“记录与备份”导出 JSON；本地文件版本的进度需导出后再导入在线版本。

旧版教材位于 `legacy/index.html`；教学 CSV、Python 和表格操作说明位于 `materials/`，也可从网站内下载。

阅读界面于2026-11-08重构：沙色纸面、细线与柔和配色，连续正文、按阶段折叠的课程导航、桌面页边索引与当前小节提示。首页入场、主动展开和指定按钮反馈参考React Bits，已原生适配并内嵌，支持系统减弱动效；来源及完整许可见[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

当前采用暖白正文、灰绿辅助区、赭黄标题、青绿当前项，局部漫画交叉排线和双道墨线；正文不铺纹理。

右上角“阅读设置”支持字体、字号、行距、正文最大宽度，以及明亮／护眼纸色／夜间配色。桌面可拖动侧栏右侧把手调宽，或聚焦后用方向键调整；双击恢复默认，也可在设置内使用滑杆。侧栏滚动条默认闲置时隐藏，交互时显示。

外观偏好在当前浏览器自动保存，恢复默认只影响外观。外观偏好不计入课程JSON备份；换浏览器需重新调整。护眼纸色是舒适度选项，按环境光和自己的感受选择。

## 教学材料

示范数据为人工构造，访谈和文本样稿为原创教学情境，不能作为实际科研成果。各学科方法、报告与申请要求按相关机构和具体研究条件理解。

本仓库通过 GitHub Pages 发布静态网页。更新根目录 `index.html` 后推送到 `main`，Pages 会重新发布。
