# 用表格完成配对分析

## 1. 导入并检查

在Excel用“数据 → 从文本/CSV”导入 teaching-measurements.csv，分隔符为逗号。保留原始A:E列，确保第1行为列名，第2到21行为20个对象。检查ID没有重复，每行两种流程对应同一对象。若数字变成文本或全部挤在一列，先修正导入设置再计算。

## 2. 添加计算列

F1填abs_error_a_g，G1填abs_error_b_g，H1填difference_g。

- F2：`=ABS(C2-B2)`
- G2：`=ABS(D2-B2)`
- H2：`=G2-F2`

选F2:H2向下填充到21行。第一行应得到2、1、-1；第五个对象应得到2.5、2.7、0.2。正差不是错误数据，它表示这个对象B的绝对误差更大，不能为了平均表现更好而删除。

## 3. 写汇总区

J列填写指标名，K列输入下列公式。

| 单元格 | 指标 | 公式 |
| --- | --- | --- |
| K2 | 对象数 | `=COUNT(H2:H21)` |
| K3 | A平均绝对误差 | `=AVERAGE(F2:F21)` |
| K4 | B平均绝对误差 | `=AVERAGE(G2:G21)` |
| K5 | 平均配对差 | `=AVERAGE(H2:H21)` |
| K6 | 差值样本标准差 | `=STDEV.S(H2:H21)` |
| K7 | 标准误 | `=K6/SQRT(K2)` |
| K8 | 自由度 | `=K2-1` |
| K9 | 95%双侧t临界值 | `=T.INV.2T(0.05,K8)` |
| K10 | 区间下限 | `=K5-K9*K7` |
| K11 | 区间上限 | `=K5+K9*K7` |
| K12 | t统计量 | `=K5/K7` |
| K13 | 双侧p | `=T.DIST.2T(ABS(K12),K8)` |
| K14 | 配对检验交叉核对 | `=T.TEST(F2:F21,G2:G21,2,1)` |

部分地区Excel使用分号分隔参数，按本机设置替换逗号。K14的最后参数1代表配对检验；双侧p不受差值符号方向影响，但结果解释和t符号受方向影响。

核对：n=20；A均值3.75g；B均值3g；平均差-0.75g；SD约0.662134g；SE约0.148058g；t约-5.065596；95%CI约[-1.059888,-0.440112]g；双侧p约0.0000686813。显示三位小数不代表测量具有千分之一克精度。

## 4. 画出与Python相同的两部分图

第一张图显示所有对象的配对差。I1填object_number，I2:I21填1到20；选择H2:I21，插入“散点图（仅标记）”。在“选择数据→编辑系列”中确认X值是H2:H21，Y值是I2:I21，不能把序号误当成差值。横轴标题写“绝对误差差 B−A（g）”，纵轴写“模拟对象序号”。将纵轴最小值设为0.5、最大值20.5、主单位1；需要与Python图方向一致时勾选“逆序刻度值”，使对象1在上方。序号只代表ID顺序，不是时间。

另建一列两行辅助数据：X都为0，Y分别为0.5和20.5。把它添加为新系列，设置为带直线的散点图并去掉标记，得到零差参考线。横轴可固定−2.25至0.75，与Python图范围相同。核对16个点在零线左侧、1个在零线上、3个在右侧。Python图额外从零点连到每个对象差值，便于读方向；线段不代表观测之间的趋势。

第二张图显示均值及其95%模型区间。M1:P1依次填mean_g、display_y、negative_error、positive_error；M2填`=K5`，N2填0，O2填`=K5-K10`，P2填`=K11-K5`。以M2为X、N2为Y插入单点散点图。通过“图表元素→误差线→其他选项”选择水平X误差线，误差量选“自定义”：正误差值引用P2，负误差值引用O2。若软件自动增加垂直Y误差线，将它删除。

均值点应在−0.750 g；左右端点应为−1.060和−0.440 g。不要把区间上下端点本身直接填作误差长度：误差长度是“均值到端点的距离”，这里两边约0.309888 g。第二图同样添加x=0的参考线，横轴范围设为−2.25至0.75；纵轴仅用来摆放单点，没有研究含义。图题写“均值与配对t模型95%置信区间”，图注注明数据人工构造、20个配对对象。

可额外画H列的直方图，帮助观察分布是否被极少数值支配；它不属于上述两部分成品图。小样本图形不能证明正态，也不应机械根据一个正态检验p值选择全部后续方法。均值区间不是SD、SE或20个原始差值的范围。

## 5. 做一个可核对的敏感性检查

在新的空列Q1写leave_one_out_mean，Q2输入`=(SUM($H$2:$H$21)-H2)/(COUNT($H$2:$H$21)-1)`，向下填充到Q21。每行只是暂时留出对应对象后的均值计算；不要删除原始数据。`=MIN(Q2:Q21)`应约为−0.810526，`=MAX(Q2:Q21)`约为−0.684211。`=MEDIAN(H2:H21)`为−0.75。20次重算方向相同，说明这个构造样本的平均方向不完全由单个对象决定；不能据此排除系统偏差、混杂或证明推广有效。

## 6. 写结果与限制

可写：“在20个构造对象中，B−A的平均绝对误差差为-0.750g，配对t模型下95%区间为[-1.060,-0.440]g。16个对象B误差更低，3个更高，1个相同。”紧接着写“数据是人工构造，仅展示方法，不证明真实流程B有效”。

保留原CSV、带公式的工作簿、图表和结果文字。给图注写输入文件、差值定义、样本单位及模拟身份。不要只保存截图，以免别人无法检查公式或重新计算。
